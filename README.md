# MiniBank

Учебный банковский сервис на Go, на котором я разбирался с чистой архитектурой: как разделить домен, бизнес-логику и адаптеры так, чтобы слои не знали лишнего друг о друге.

Сервис умеет создавать пользователей, показывать их (с пагинацией), проводить транзакции (пополнение и списание с проверкой баланса) и удалять пользователей.

## Стек

- **Go 1.25**, роутер — gorilla/mux
- **PostgreSQL** (драйвер pgx/v5, пул соединений)
- Миграции — golang-migrate
- Логирование — slog
- Docker

## Архитектура

Проект разбит по принципам clean architecture:

```
cmd/minibank/        — точка входа, сборка зависимостей
internal/
  domain/users/      — домен: модель User, интерфейс Storage,
                       бизнес-логика (BankService), доменные ошибки
  adapters/
    api/             — HTTP-слой: хендлеры, роутер, DTO, маппинг ошибок
    db/              — репозиторий на PostgreSQL
    config/          — конфигурация из переменных окружения
  logger/            — обёртка над slog
```

Главная идея, которую я здесь отрабатывал: домен не зависит ни от HTTP, ни от базы. `BankService` работает с интерфейсом `Storage`, поэтому в тестах базу можно подменить моком, а слой API общается с доменом через DTO и переводит доменные ошибки в HTTP-статусы.

Ещё в проекте есть graceful shutdown: сервер корректно завершает работу по SIGINT/SIGTERM с таймаутом 5 секунд.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/bank` | Список пользователей (пагинация через `?page=N`) |
| GET | `/bank/{id}` | Пользователь по UUID |
| POST | `/bank` | Создать пользователя `{"full_name": "..."}` |
| POST | `/bank/{id}/transaction` | Транзакция `{"type": "deposit"/"withdraw", "amount": N}` |
| DELETE | `/bank/{id}` | Удалить пользователя |
| GET | `/bank/health` | Проверка живости |

Ошибки возвращаются в едином формате: JSON с текстом ошибки и временем.

## Как запустить

1. Поднимите PostgreSQL и создайте базу `minibank`.
2. Скопируйте `.env.example` в `.env` и укажите свои `PORT` и `DATABASE_URL`.
3. Примените миграции:

```bash
make migrate-up
```

4. Запустите сервис:

```bash
go run ./cmd/minibank
```
